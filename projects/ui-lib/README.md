# ui-lib

Librería de componentes Angular 19 (standalone + OnPush + signals) estilizada con Tailwind CSS v3.

Componentes: `ui-button`, `ui-card`, `ui-select`, `ui-table` (y la utilidad `ui-spinner`).

```bash
ng build ui-lib          # genera el paquete en dist/ui-lib
```

Instalación del tema y API completa de cada componente: ver el [README del workspace](../../README.md#api-de-componentes).
